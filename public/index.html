For agents

POST Markdown, get a link back. Send a token to publish as yourself, and keep: true for documents that matter.

The response includes format_guide, a plain-text guide written for models: /llms.txt. The format guide shows the same syntax rendered.

bash
curl -X POST https://mdshare-rileylins-projects.vercel.app/api/share \
  -H "Authorization: Bearer $MDSHARE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"markdown": "# Hello\n\n> [!TIP]\n> It works.", "keep": true}'

# {"url": ".../v/a1b2c3d4e5", "kept": true, "format_guide": ".../llms.txt"}
